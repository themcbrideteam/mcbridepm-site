# DESIGN REQUIREMENTS

# CONVERSION STRATEGY

Every page must have a single primary objective.

Possible goals include: Request a Rental Analysis, Schedule a Consultation, Call the Office, Text Our Team, Submit an Owner Inquiry, Browse Available Rentals, Apply for a Home, Download a Resource.

No page should exist without a measurable conversion goal.

Reduce friction wherever possible.

---

# TRUST ARCHITECTURE

Continuously strengthen trust using: client testimonials, Google reviews, resident feedback, case studies, success stories, years of experience, homes managed, occupancy statistics, response-time metrics, maintenance performance, professional certifications, licensing, insurance, local expertise, transparent pricing, clear processes, educational resources, frequently asked questions.

Trust should be visible before visitors begin looking for it.

---

# CONTENT STRATEGY

Rewrite content whenever necessary. Focus on outcomes rather than features. Replace vague claims with measurable benefits. Use concise, confident language. Write naturally for both humans and AI systems.

Ensure every page answers: Why choose us? Why now? Why trust us? What happens next?

Remove unnecessary words. Increase clarity. Increase authority. Increase confidence.

---

# SEO / AEO / GEO

Optimize for: semantic SEO, technical SEO, entity optimization, local SEO, schema markup, Knowledge Graph relevance, internal linking, topical authority, content clustering, Google AI Overviews, ChatGPT, Gemini, Claude, Perplexity, voice search, featured snippets, People Also Ask, zero-click search, search intent.

Optimize for users first. Search engines second. AI systems third.

---

# PERFORMANCE STANDARDS

Target: Lighthouse Performance ≥95, Accessibility = 100, SEO = 100, Best Practices = 100. Minimal JavaScript, optimized images, Core Web Vitals passing, fast interactions, minimal layout shift, fast navigation.

Every optimization should improve speed without sacrificing quality.

---

# DECISION FILTER

Before making any change, ask:

Does this improve trust? Does this reduce friction? Does this simplify the experience? Does this increase clarity? Does this improve accessibility? Does this increase conversion probability? Does this strengthen premium positioning? Does this improve long-term maintainability?

If the answer is no, reject the change.
